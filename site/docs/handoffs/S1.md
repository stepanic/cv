Paket:

1. **Baseline sadržaja (najprije, jer o njemu ovisi sve ostalo).** `npm --prefix web ci && npm --prefix web run build`, pa posluži `web/out` lokalno (bilo koji statički server; Next export koristi `blog/<slug>.html`, pa server mora rješavati putanje bez `.html`). Playwright (devDependency u `site/`, Chromium se skida jednom pri instalaciji) za svaku rutu (`/`, `/blog`, i svih 9 `/blog/<slug>`, popis slugova iz `web/content/blog.ts`) i za oba jezika (EN bez parametra; HR s `?lang=hr` uz prazan localStorage) čeka hidraciju i sprema `document.body.innerText` u `site/test/baseline/{en,hr}/<ruta>.txt`. Provjeri da HR dump stvarno sadrži hrvatski tekst (npr. naslov sekcije iz `web/lib/i18n/messages.ts`), inače baseline ne vrijedi. Skripta ide u `site/scripts/baseline.mjs` da se može ponoviti. Ako baseline HR verzije ne uspije ni na jedan način, zapiši zašto i stani: bez njega parity nije mjerljiv.
2. **Baseline težine:** `site/scripts/weight.mjs <outDir>` za svaki HTML zbroji bajtove HTML-a i svih `<script src>` i `<link rel=stylesheet>` koje referencira. Pokreni nad `web/out` i spremi `site/test/baseline/next-weight.json`. Polazna brojka iz S0 je 524 KB JS-a na `/`; potvrdi je ili ispravi.
3. **Astro projekt u `site/`:** zadnji stabilni Astro, `@astrojs/react`, Tailwind 3 (odluka 8; točne verzije kao odluka 100+). Static output u `site/dist`. Kopiraj `web/tailwind.config.ts`, `web/app/globals.css`, `web/public/*` (uključivo `_headers` i `.ots` fajlove). `site/.gitignore` za `node_modules`, `dist`, `.astro`.
4. **Data i i18n na buildu:** port `web/lib/data.ts` (čita `../data` relativno na `site/`), `types.ts`, `format.ts`. Iz `web/lib/i18n/` uzmi `messages.ts` i plural pravila, a `t`, `lt`, `n` napravi kao obične funkcije s jezikom kao argumentom (bez React contexta).
5. **Layout i prve rute:** `src/layouts/Base.astro` s `<html lang>` po ruti, metapodacima iz `web/app/layout.tsx` i theme skriptom prije prvog painta (ključ `stepanic.theme`). Port `Hero` kao `.astro`. Rute `src/pages/index.astro` (EN) i `src/pages/hr/index.astro` (HR) zasad prikazuju samo Hero.
6. **Parity skripta:** `site/scripts/parity.mjs` poslužuje `site/dist` lokalno, Playwrightom uzima `innerText` istih ruta i uspoređuje s baselineom nakon normalizacije razmaka. Za S1 dovoljno je da provjeri da je svaki redak Hero dijela iz baselinea prisutan; od S2 se postrožuje na punu stranicu. Ispis: po ruti broj nedostajućih i viškova redaka.
7. **`npm --prefix site run check`:** `astro check && astro build && node scripts/parity.mjs && node scripts/weight.mjs dist`.

Ne diraj `web/`, `web/wrangler.jsonc` ni `.github/workflows/ci.yml` (odluka 7).
